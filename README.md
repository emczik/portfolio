Zależało mi na połączeniu prostego, nowoczesnego wyglądu z klimatem tech/gaming, który pasuje do moich zainteresowań i projektów.

Strona zawiera:

* responsywny wygląd na komputerach i telefonach

## 🚀 Projekty prezentowane w portfolio

### 🧸 Squeeze Simulator

Własna gra typu clicker tworzona w Roblox Studio.

Projekt zawiera między innymi system progresji, questy, ulepszenia, kolekcję gniotków, modele 3D, zapis danych gracza oraz sklep premium.

**Technologie:** Roblox Studio • Lua • UI • Game Design • DataStore

### 🏠 RentPredict

> 🚧 Projekt w trakcie rozwoju

Platforma do analizy i przewidywania cen wynajmu mieszkań na podstawie danych z rynku nieruchomości.

**Obszary:** Web • Data • Real Estate • Prediction
